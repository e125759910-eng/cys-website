===============================================================
Vercel KV 配置步骤 - 5分钟快速配置
===============================================================

⚠️ 重要：在 Vercel 环境中必须配置 KV 存储才能新增和删除保固记录！

===============================================================
步骤 1: 创建 KV 数据库（2分钟）
===============================================================

1. 打开 Vercel Dashboard
   https://vercel.com/dashboard

2. 选择项目：cys-website

3. 点击左侧菜单 "Storage"

4. 点击 "Create Database" 按钮

5. 选择 "KV" 类型

6. 数据库名称：cys-warranties（或任意名称）

7. 选择区域：Southeast Asia (Singapore) 或 East Asia (Tokyo)

8. 点击 "Create"

===============================================================
步骤 2: 获取连接信息（1分钟）
===============================================================

1. 点击刚创建的 KV 数据库

2. 在页面中找到 "REST API" 部分

3. 复制以下信息：
   - REST API URL（类似：https://xxx.upstash.io）
   - REST API Token（一长串字符）

   ⚠️ 请妥善保存这些信息！

===============================================================
步骤 3: 设置环境变量（1分钟）
===============================================================

1. 在项目页面，点击顶部 "Settings" 标签

2. 点击左侧菜单 "Environment Variables"

3. 添加第一个环境变量：
   - 点击 "Add New"
   - Name: KV_REST_API_URL
   - Value: 粘贴刚才复制的 REST API URL
   - Environment: ✅ 勾选 "Production"（必须！）
   - 点击 "Save"

4. 添加第二个环境变量：
   - 点击 "Add New"
   - Name: KV_REST_API_TOKEN
   - Value: 粘贴刚才复制的 REST API Token
   - Environment: ✅ 勾选 "Production"（必须！）
   - 点击 "Save"

5. 确认：
   - 应该看到两个环境变量：
     ✅ KV_REST_API_URL
     ✅ KV_REST_API_TOKEN
   - 两个变量都应用于 Production 环境

===============================================================
步骤 4: 重新部署（1分钟）
===============================================================

1. 点击顶部 "Deployments" 标签

2. 找到最新的部署记录

3. 点击右侧 "..." 菜单

4. 选择 "Redeploy"

5. 确认重新部署

6. 等待部署完成（通常 1-2 分钟）
   - 状态变为 "Ready" 表示完成

===============================================================
步骤 5: 验证配置（30秒）
===============================================================

1. 访问后台管理页面
   https://your-domain.com/admin/login

2. 登录后台

3. 点击 "系统诊断" 按钮

4. 应该看到：
   ✅ 存储类型: kv
   ✅ KV 已配置: 是
   ✅ KV URL 已设置: 是
   ✅ KV Token 已设置: 是

5. 测试功能：
   - 点击 "新增保固"
   - 填写测试数据
   - 点击 "新增"
   - 应该成功保存！

===============================================================
常见问题
===============================================================

Q: 环境变量设置了但诊断还是显示未配置？
A: 检查是否勾选了 "Production" 环境，然后重新部署

Q: 部署后还是显示错误？
A: 等待 1-2 分钟让部署完全完成，清除浏览器缓存，重新登录

Q: 如何确认 KV 数据库已创建？
A: 在 Storage 页面应该能看到 KV 数据库，状态为 "Active"

Q: 环境变量值从哪里获取？
A: 在 KV 数据库详情页面的 "REST API" 部分
